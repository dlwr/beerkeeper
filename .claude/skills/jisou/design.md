# デザインの方針

UI の PR はこの方針に従う。変えるときはこのファイルを先に直す。

## 土台

- Bootstrap 5.3 を残し、Sass の変数で上書きする（`app/assets/stylesheets/application.bootstrap.scss`）。既存の画面がすべて Bootstrap のクラスで組まれていて、捨てると全画面を一度に作り直すことになるため
- 独自の部品は `site-` で始まる BEM 風のクラスにし、同じファイルに書く
- 色・余白・文字の値はこのファイルの段階からだけ選ぶ。画面ごとに新しい値を足さない

## 色

| 役割 | 値 | 使い方 |
| --- | --- | --- |
| 背景 | `#fff` | ページの地。白だけを使う |
| 面 | `#f6f8fa` | 区切りたいまとまりの地（寒色のグレー） |
| 文字 | `#1f2328` | 本文・見出し |
| 補足の文字 | `#59636e` | 日付の補足・空の状態など（白地で 6:1） |
| 線 | `#d0d7de` | 区切り線・カードの枠 |
| 強い線 | `#8c959f` | 入力欄・副ボタンの枠（白地で 3:1） |
| アクセント | `#f9c023` | ロゴのビールの黄色。主ボタンの地だけに使い、文字は `#1f2328` |
| リンク | `#7a4100` | 本文中のリンク（白地で 7:1 以上）。下線を残す |
| 危険 | `#b42318` | エラー・取り消せない操作 |
| 成功 | `#1a7f37` | 完了の知らせ |

- 文字のコントラストは WCAG AA（4.5:1）以上。状態は色だけで伝えず、文字を添える

## 文字

- 書体はシステムフォント（`system-ui`、ヒラギノ角ゴ、Noto Sans JP、游ゴシック UI）。Web フォントは読み込まない
- 段階: 14px（補足）/ 16px（本文・入力欄）/ 18px / 20px / 24px（h2）/ 28px（h1）。h1 は 1 画面に 1 つ
- 本文の行間は 1.7、見出しは 1.35。見出しは太字（700）で、斜体は使わない
- 入力欄は 16px 未満にしない（iOS の拡大を避ける）

## 余白

- 段階: 4 / 8 / 12 / 16 / 24 / 32 / 48px（Bootstrap の `1`〜`7`）
- 本文の幅は最大 1040px（`container`）。左右の余白はスマホで 12px 以上

## 部品

- ボタン: 高さ 44px 以上、角丸 6px、太字。主ボタン（`btn-primary`）は 1 画面に 1 つで、ヘッダーには置かない。ほかは `btn-outline-secondary`。取り消せない操作は `btn-outline-danger` にして主ボタンから離す
- リンク: 下線付き。タップ対象として単独で置くときは 44px の高さを取る
- 入力欄: 高さ 44px 以上、角丸 6px、枠は強い線。`<label>` を必ず結びつけ、必須・任意を文字で書く。エラーは欄の直下に危険の色と文字で出す
- カード: 1px の線の枠、角丸 8px、影なし。並べるときは縦の一覧にする
- フラッシュ: 左に 4px の線を付けた帯。成功は `role="status"`、エラーは `role="alert"`
- アイコン: Bootstrap Icons を文字の補助としてだけ使い、`aria-hidden="true"` を付ける。アイコンだけのボタンは作らない
- フォーカス: 3px の `#1f2328` の輪郭を 2px 離して出す。消さない

## レイアウト

- 先頭に「本文へ移動」のスキップリンク、`<header>` の中にロゴとナビ（`aria-label="メイン"`）、本文は `<main id="main">`
- ヘッダーは白地に下線 1 本。ロゴはスマホで幅 104px、md 以上で 160px。ナビはスマホでも 1 行に収める

## 使わないもの

オーナーの指定。

- クリーム色・オフホワイトの背景
- 見出しの中の一語だけをイタリックにする強調
- 「01 / 02 / 03」の番号付きセクションラベル
- 等幅フォントのラベル
- ピル型ボタン（`rounded-pill` も使わない）
- 紫系のグラデーション
- 絵文字のアイコン
- 角丸カードの 3 列グリッド
